# AME E Category - Avionics Exam Prep

Separate GitHub Pages site using the same interface as the AME M practice site.

## Banks
- SPE - Standard Practices Avionics: 240 questions
- AV - Avionics All Systems: 240 questions
- Mixed SPE + AV mode

Includes original inline SVG diagrams for selected circuit, waveform, logic, synchro, RF/navigation, autopilot, pitot-static and air-data questions. The diagrams are independent study graphics and are not reproductions of Transport Canada exam material.

Features: 25/50/90/100/200/all, Practice and Exam modes, optional timer, question/answer shuffle, progress, previous/next, restart, main menu, result breakdown and incorrect-answer review.

Question scope is organized around TP 14038 E-rating Standard Practices Avionics and Avionics subject areas. This is an independent study aid and is not affiliated with Transport Canada.


## Visual v2 update

These are original practice figures, not reproduced Transport Canada exam images.
